## 2. Core Mathematical Architecture & Calculation Path

Formula F10 v2 enforces strict end-to-end data lineage from raw Shopify Admin GraphQL objects down to normalized atomic Line Facts and aggregated Variant Rollup Metrics.

```
Shopify Admin GraphQL Bulk Query (API 2024-10 LTS)
   │
   ├── Order Grain (id, createdAt, processedAt, cancelledAt, test, taxesIncluded, totalPriceSet)
   │      │
   │      ├── Gate DQ-S4: Filter Test Orders (order.test == true)
   │      └── Gate DQ-T1: Determine Cohort Date & Maturity (processedAt in shop timezone)
   │
   ├── Order-Level Allocations (Carrier Shipping & Payment Gateway Fees)
   │      │
   │      ├── Outbound Courier: allocate_largest_remainder(carrier_flat_rate, line_net_shares)
   │      ├── Shipping Collected: allocate_largest_remainder(shipping_charged, line_net_shares)
   │      └── Gateway Fees: allocate_largest_remainder(total_fees, line_net_shares) [Tie-Break: Lowest Index]
   │
   ├── Refund & Restock Parsing (refundLineItems, orderAdjustments)
   │      │
   │      ├── Unit Taxonomy: q_refunded, q_restocked, q_not_restocked = max(0, q_refunded - q_restocked)
   │      ├── Restock Disposition (PR-11): RESTOCK/RETURN -> recover cost; NO_RESTOCK -> lost
   │      └── Goodwill Allocation (PR-12): orderAdjustments allocated proportionally across lines
   │
   └── Normalized Line Fact (compute_line_fact)
          │
          ├── 1. Retained Revenue = NetBilled - RefundItem - Goodwill
          ├── 2. COGS Lost = (q_shipped - q_refunded + q_not_restocked) * CostSnapshot
          ├── 3. Physical Returns = q_restocked + (q_not_restocked if policy=lost else 0)
          ├── 4. Operational Costs = Outbound + Fees + ReturnShip*phys + Handling*phys + Packaging*q_shipped
          ├── 5. Contribution = RetainedRev - COGS_lost - OperationalCosts
          └── 6. Quarantine Audit: Cost missing/zero -> flag cogs_missing / cogs_zero_suspect
                 │
                 └── Variant Rollup Metric (rollup_variant_metrics)
                        ├── Scored vs Quarantined Revenue Segregation
                        ├── Unknown Cost Share Gate: quarantined_rev / total_rev > 15% -> UNSCOREABLE
                        ├── Margin Pct = (Contribution / RetainedRev) * 100 (null if RetainedRev <= 0)
                        ├── Score = clamp(Margin, 0, 100) (0 if RetainedRev <= 0 and costs > 0)
                        └── Hidden Leakage Waterfall = NaiveProfit - Contribution (Exact Identity)
```

### Strict Mathematical Formulations

1. **Net Billed Revenue ($R_{\text{billed}}$)**:
   $$R_{\text{billed}} = P_{\text{gross}} - D_{\text{line}}$$

2. **Retained Revenue ($R_{\text{retained}}$)**:
   $$R_{\text{retained}} = R_{\text{billed}} - R_{\text{refund}} - R_{\text{goodwill}}$$

3. **Incurred Inventory COGS ($C_{\text{lost}}$)**:
   Under policy `lost` or `kept_by_customer`:
   $$C_{\text{lost}} = (Q_{\text{shipped}} - Q_{\text{refunded}} + Q_{\text{not\_restocked}}) \times C_{\text{snapshot}}$$
   *Restocked units return to sellable inventory and incur zero permanent inventory write-off.*

4. **Physical Reverse Returns ($Q_{\text{phys}}$)**:
   $$Q_{\text{phys}} = Q_{\text{restocked}} + \begin{cases} Q_{\text{not\_restocked}} & \text{if policy} = \text{lost} \\ 0 & \text{if policy} = \text{kept\_by\_customer} \end{cases}$$

5. **Operational Reverse & Outbound Logistics Costs**:
   - Outbound Net Courier Cost: $O = C_{\text{carrier\_allocated}} - S_{\text{shipping\_charged\_allocated}}$
   - Reverse Shipping: $S_{\text{return}} = Q_{\text{phys}} \times \text{Rate}_{\text{return\_ship}}$
   - Return Handling / Inspection: $H = Q_{\text{phys}} \times \text{Rate}_{\text{handling}}$
   - Fulfillment Packaging: $P = Q_{\text{shipped}} \times \text{Rate}_{\text{pick\_pack}}$

6. **Product Contribution Dollars ($\Pi_{\text{contrib}}$)**:
   $$\Pi_{\text{contrib}} = R_{\text{retained}} - C_{\text{lost}} - O - \text{Fees} - S_{\text{return}} - H - P$$

7. **Contribution Margin Percentage ($M$) & Score ($S$)**:
   $$M = \begin{cases} \left(\frac{\Pi_{\text{contrib}}}{R_{\text{retained}}}\right) \times 100 & \text{if } R_{\text{retained}} > 0.00 \\ \text{null} & \text{if } R_{\text{retained}} \le 0.00 \end{cases}$$
   $$S = \begin{cases} \text{clamp}(M, 0.00, 100.00) & \text{if } R_{\text{retained}} > 0.00 \\ 0.00 & \text{if } R_{\text{retained}} \le 0.00 \text{ and Costs} > 0.00 \\ \text{null} & \text{if } R_{\text{retained}} \le 0.00 \text{ and Costs} = 0.00 \end{cases}$$

8. **Naive Gross Profit ($\Pi_{\text{naive}}$) & Hidden Leakage ($L_{\text{leakage}}$)**:
   $$\Pi_{\text{naive}} = R_{\text{billed}} - (Q_{\text{shipped}} \times C_{\text{snapshot}})$$
   $$L_{\text{leakage}} = \Pi_{\text{naive}} - \Pi_{\text{contrib}}$$

### 9.4 Enumerations & Value Domains

#### VariantStatus
- `HEALTHY`: Scored variant with `margin_pct >= healthy_margin` (default 25.00%).
- `UNDERPERFORMING`: Scored variant with `0.00% < margin_pct < healthy_margin`.
- `BREAKEVEN`: Scored variant with `contribution == 0.00` and `margin_pct == 0.00%`.
- `VALUE_DESTROYING`: Scored variant with `contribution < 0.00` or `retained_rev <= 0.00` with positive costs.
- `UNSCOREABLE`: Variant where `unknown_cost_share > max_unknown_cost_share` (Gate DQ-K2).
- `INCOMPLETE_COSTS`: Variant with unconfigured cost components (e.g., return shipping unknown).
- `RANGE_ONLY`: Variant with bounded unknown cost components (bounds configured, no exact point).
- `UNRESOLVED`: Variant with unresolvable inventory disposition under `no_restock_policy: unknown`.
- `NO_DATA`: Variant with zero units shipped during the cohort window.

#### EvidenceTier
- `T1` (Verified Point-in-Time): Captured snapshot from Shopify API at transaction time.
- `T2` (Confirmed Contractual): Merchant-confirmed flat rate or confirmed zero cost.
- `T3` (Modelled / Backfilled): Fallback fee formula or current catalog cost snapshot.
- `T4` (Missing / Unknown): Value unknown; quarantined or marked incomplete.

#### CogsState
- `COGS_OBSERVED`: Non-zero unit cost snapshot present.
- `COGS_MISSING`: Unit cost snapshot is null (routes to quarantine).
- `COGS_ZERO_SUSPECT`: Unit cost is $0.00 on non-free merchandise (routes to quarantine).

## 10. Business Governance & Ratified Stakeholder Decisions

1. **Decision D1 (Restock Interpretation):** Restocked units restore inventory cost (`cogs_lost = 0`). Non-restocked units carry COGS write-off under policy `lost` and `kept_by_customer`. If policy is `unknown`, calculation is halted as `UNRESOLVED`.
2. **Decision D14 (Cohort Window Definition):** 30 calendar days inclusive in the merchant's configured shop timezone (`America/New_York`), preventing UTC boundary rollover leakage.
3. **Decision D15 (Quarantine Gate Denominator):** Gate DQ-K2 uses `quarantined_revenue / total_billed_revenue` because retained revenue can be zero or negative.
4. **Decision D16 (Unknown Cost Components):** Unconfigured costs result in status `INCOMPLETE_COSTS` (or `RANGE_ONLY` if bounds configured). Never silent zero imputation.
5. **Decision D17 (Deterministic Tie-Breaking):** Largest-remainder penny ties are awarded to the lowest line item index (`(-fraction, index)`), guaranteeing 100% reproducible allocations.
6. **Decision D18 (Cohort Restatement Rule):** Refunds dated after `as_of` are invisible on earlier runs. When evaluated at a later `as_of`, the refund is attributed to the original order cohort.
